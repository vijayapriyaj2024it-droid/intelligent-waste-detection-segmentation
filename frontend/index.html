How our model processes waste images step-by-step

02

Preprocess

Image is resized, mapped into RGB, and normalized for standard tensor sizing.

03

04

Classify & Advise

About Project

Project Name: Intelligent Waste Detection & Segmentation

Problem Statement: Inefficient and manual waste sorting causes recycling contamination and slow processing speeds.

Solution: Automated image classification and segmentation using Computer Vision algorithms based on the TACO dataset standard.

6 Project Categories: Plastic, Metal, Glass, Paper/Cardboard, Food Waste, Foam.
